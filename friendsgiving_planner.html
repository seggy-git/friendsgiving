Friendsgiving 6: Whoops I missed one

The sixth annual Friendsgiving celebration at our home, a time for us get together and be thankful for all that is good - Beer, Food, and Friends, in no particular order.

Same as every year, I will be preparing a turkey. Feel free to bring any dish you want but don't feel obligated. We'll just silently judge you if you come empty handed and at some point tell you to get the fuck out.

As always, there will be plenty of beer and booze, and we can sleep, like, 6-8 people now so if you need to crash that is cool too.

How to Host This App

Quick guide to deploying and sharing with friends

1 Free Hosting Options

Because this app is contained in a single index.html file, you can host it for free in under 2 minutes:

  • Netlify Drop: Drag & drop the file into Netlify Drop.
  • GitHub Pages: Push to a GitHub repository and turn on Pages in settings.
  • Vercel / Render: Import as a static HTML project.

2 How Data Storage Works

This app automatically saves state to the user's local browser memory (localStorage).
